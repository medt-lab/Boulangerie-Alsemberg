4. Technologies

Front-end

  • HTML5 sémantique
  • CSS3 (variables, grid, animations)
  • JavaScript vanilla (ES6+)

Services

  • Google Fonts (DM Sans, Playfair Display)
  • WhatsApp API (envoi de devis)
  • Unsplash (images externes)
  • GitHub Pages (hébergement)
  • LWS (domaine + emails)

5. Fonctionnalités JavaScript

  • Menu mobile : Toggle responsive avec animation
  • Header sticky : Ombre au défilement
  • Reveal on scroll : Apparition progressive des éléments (IntersectionObserver)
  • Navigation active : Section visible surlignée
  • Préselection occasion : Clic sur les cartes événementielles
  • Formulaire WhatsApp : Construction du message et ouverture de WhatsApp
  • Date minimum : Date d'événement = aujourd'hui minimum
